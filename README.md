# IaConcentrada: Seoul Bike Rental Prediction

This repository contains the project codebase and documentation for predicting rental bike demand in Seoul using Machine Learning models.

## Repository Structure

* **ETL_SeoulBike_CleanCode.py**: Clean and modular pipeline for Data Extraction, Transformation, and Loading (ETL).
* **seoulbikes_stepbystep.py**: Official step-by-step history and detailed record of the exploratory workflow.
* **ML_Model__Rented_Bikes_Demand_in_Seoul.pdf**: Documentation and technical report for the Machine Learning model.

## Project Status

* **ETL Phase**: Fully completed, formatted and documented.
* **EDA Phase**: In active progress. Exploratory Data Analysis insights and refined code will be added in upcoming updates.
